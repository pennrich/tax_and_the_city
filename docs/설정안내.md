# 세금 퀴즈 게임 설정 안내

처음 한 번만 하면 됩니다. 1~5단계는 Firebase(실시간 연결), 6~7단계는 GitHub Pages(웹사이트 올리기)입니다.
모두 무료 요금제로 충분합니다.

---

## 1. Firebase 프로젝트 만들기

1. 크롬에서 **https://console.firebase.google.com** 에 들어가 구글 계정으로 로그인합니다.
2. **"프로젝트 만들기"**(또는 "Firebase 프로젝트 시작하기")를 누릅니다.
3. 프로젝트 이름에 `tax-quiz` 처럼 원하는 이름을 쓰고 **계속**을 누릅니다.
4. "Google 애널리틱스"는 **사용 안 함**으로 끄고 **프로젝트 만들기**를 누릅니다.
5. 잠시 뒤 "새 프로젝트가 준비되었습니다"가 나오면 **계속**을 누릅니다.

## 2. 웹 앱 등록하고 설정값 붙여넣기

1. 프로젝트 첫 화면 가운데의 **`</>`(웹)** 아이콘을 누릅니다.
2. 앱 닉네임에 `quiz-web`이라고 쓰고, "Firebase 호스팅 설정"은 **체크하지 않고** **앱 등록**을 누릅니다.
3. 화면에 아래처럼 생긴 코드가 나옵니다.
   ```js
   const firebaseConfig = {
     apiKey: "AIza....",
     authDomain: "tax-quiz-xxxx.firebaseapp.com",
     projectId: "tax-quiz-xxxx",
     ...
     appId: "1:1234:web:abcd"
   };
   ```
4. 이 프로젝트 폴더의 **`js/config.js`** 파일을 메모장으로 열어 `apiKey`, `authDomain`, `projectId`, `appId` 값을 따옴표 안에 그대로 복사해 넣습니다.
   `databaseURL`은 4단계에서 채웁니다.
5. Firebase 화면에서 **콘솔로 이동**을 누릅니다.

## 3. 로그인 방법 켜기 (교사 = 구글 로그인, 학생 = 익명)

1. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**를 누릅니다.
2. **로그인 방법** 탭에서 **Google**을 누르고 **사용 설정**을 켭니다. 프로젝트 지원 이메일에 본인 메일을 고르고 **저장**합니다.
3. 다시 **새 제공업체 추가** → **익명**을 누르고 **사용 설정**을 켜고 **저장**합니다.
4. **설정** 탭 → **승인된 도메인** → **도메인 추가**를 눌러 `내GitHub아이디.github.io` 를 추가합니다.
   (예: GitHub 아이디가 `kimteacher`라면 `kimteacher.github.io`)

## 4. Realtime Database 만들기

1. 왼쪽 메뉴 **빌드 → Realtime Database** → **데이터베이스 만들기**를 누릅니다.
2. 위치는 **싱가포르(asia-southeast1)** 를 고르고 **다음**을 누릅니다.
3. **잠금 모드로 시작**을 고르고 **사용 설정**을 누릅니다.
4. 데이터 탭 맨 위에 보이는 주소(`https://tax-quiz-xxxx-default-rtdb.asia-southeast1.firebasedatabase.app`)를 복사해서
   `js/config.js`의 `databaseURL` 따옴표 안에 붙여넣고 저장합니다.

## 5. 보안 규칙 붙여넣기

학생이 정답이나 다른 팀 잔액을 몰래 볼 수 없게 막는 규칙입니다.

1. Realtime Database 화면에서 **규칙** 탭을 누릅니다.
2. 이 프로젝트 폴더의 **`database.rules.json`** 파일을 메모장으로 열어 **전체 내용을 복사**합니다.
3. 규칙 편집창의 내용을 **모두 지우고** 붙여넣은 뒤 **게시**를 누릅니다.

> 여기까지 끝나면 Claude에게 "설정 끝났어"라고 알려 주세요.

---

## 6. GitHub Pages에 올리기

1. **https://github.com/new** 에서 저장소를 만듭니다. (이름 예: `tax-quiz`)
2. 이 폴더를 그 저장소에 올립니다. (Claude가 대신 해 드릴 수 있습니다.)
3. 저장소의 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나타납니다.

## 7. 접속 주소

| 화면 | 주소 | 언제 |
|---|---|---|
| 준비 페이지 | `https://아이디.github.io/저장소/admin.html` | 수업 전, PC에서 |
| 교사 화면(TV) | `https://아이디.github.io/저장소/teacher.html` | 수업 시간, 교사 태블릿 |
| 학생 화면 | QR로 자동 접속 | 수업 시간, 학생 태블릿 |

## 수업 당일 순서

1. **수업 전 (PC):** 준비 페이지에서 팀·팀원·시작 금액·문항을 입력하고 **게임 저장**. (정답이 보이므로 TV에 띄우지 않기)
2. 교사 태블릿을 **TV에 연결**합니다.
3. 교사 태블릿에서 **교사 화면**을 열고 구글 로그인 → 오늘 게임을 누릅니다.
4. 학생들이 태블릿으로 **QR을 찍어** 팀과 이름을 고릅니다. 팀장(👑)은 팀 아바타를 고릅니다.
5. 입장 현황을 보고 **게임 시작**. (결석한 학생이 있어도 시작할 수 있어요)
6. 문항 번호를 눌러 문제를 내고, 시간이 끝나면 **정답 공개**.
7. 늦게 온 학생이 있으면 화면 아래 **QR 보기**를 누릅니다.
8. 마지막 문항이 끝나면 자동으로 시상식이 나옵니다. 중간에 끝내려면 **게임 종료**.

> 코드를 고친 뒤 다시 올리면 1~2분 뒤 사이트에 반영됩니다. 태블릿에서 예전 화면이 보이면 새로고침하세요.
